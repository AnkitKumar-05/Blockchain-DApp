# Blockchain-DApp — ElevateDApp

A decentralised application (DApp) built on the Ethereum blockchain as part of an NCI blockchain module project. ElevateDApp enables users to connect their MetaMask wallet, browse and purchase marketing service packages, and submit enquiries — all processed through a Solidity smart contract deployed on a local Ethereum network.

## Tech Stack

- **Frontend:** React 18, React Router v6, Bootstrap 5
- **Blockchain:** Solidity, Web3.js v1, Ethereum
- **Wallet:** MetaMask
- **Dev Network:** Ganache
- **Contract Tooling:** Truffle

---

## Quick Start

Full setup instructions including prerequisites, MetaMask configuration, Ganache setup, and smart contract deployment are in the [Elevate README](./Elevate/README.md).

```bash
# Install dependencies
cd Elevate
npm install

# Start the app (after Ganache is running and contract is deployed)
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser with MetaMask installed.
